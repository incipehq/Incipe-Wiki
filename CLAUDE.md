# Incipe Wiki — agent guide

Read this first, then the newest file in [`handoffs/`](handoffs/).

## What this app is for

Incipe sells a **B2B hardware-learning program** to schools and organisations
(the *Educational for Organization* plan): the **INCIPE Board** — an ESP32 board that
plug-and-play sensor and actuator modules snap onto — the **INCIPE Workspace** desktop
app students code it in (sibling repo `../Incipe-Workspace`), and a curriculum teachers
run. **Incipe Wiki is the public website that documents both halves:**

1. **Wiki** (`/wiki`) — *how to work with the devices.* Connecting the board, setting up
   Wi-Fi and wireless uploads, and every sensor, actuator and module: the exact
   `incipe.*` functions, what data each returns, and a 3D model of the part. The
   sensor search is the centre of it.
2. **Academy** (`/academy`) — *the learning curriculum.* Modules M1–M5 with slide
   decks (view + download), lesson notes, and the real-life projects; the full
   curriculum at `/academy/curriculum`.

Audience: students and teachers at customer schools, and prospective customers. It
is static (Vite + React 18 + react-router), deployed on Vercel, with no backend.

## Rules

- **The firmware is private. This repository and the site are public.** Never copy,
  quote or bundle the Incipe firmware references (`Incipe-Workspace/packages/skills/
  official/incipe-firmware/`), firmware source, `OTA.md`, `lifecycle.md` or any other
  internal Workspace / INCIPE-1 document into this repo. `wiki/references/` is
  git-ignored as a backstop, and `src/wikiContent.ts` deliberately reads no folder but
  `wiki/*.md` — `import.meta.glob` bundles every file it matches, used or not. Anything
  firmware-related on a Wiki page must be text the owner has approved for publication.
  Never invent or rename an `incipe.*` function.
- **The design system is copied, not edited.** `src/styles/` comes from
  `Incipe-Workspace/apps/desktop/src/renderer/`; change it there and re-copy.
- **Design system** (from the workspace's CLAUDE.md): dark-first, flat, no gradients,
  one accent read through `--signal*`, one 6px radius, 0.5px hairlines, a floating box
  takes `--edge-soft` instead of a hairline, every press is `scale(0.98)` over
  `--dur-press`, selection is `inc-row--on` (never a coloured bar), labels sentence
  case, mono only for code/buttons/machine strings. Use the existing `inc-*` classes
  before writing new CSS; no raw hex in `wiki.css`.
- **Content is data.** Add a sensor = add `wiki/<page>.md` (+ `npm run models` if it has
  a GLB). Add a lesson = add `content/<module>/<nn-page>.md` (+ `npm run ingest` if it
  has a deck). Module curriculum text is cut from `curriculum/learning-curriculum.md` —
  do not duplicate it into `content/`.
- **User-owned files** (`curriculum/`, `lessons/`, `raw/`): edit only when asked.
- Generated outputs are committed; Vercel runs only `npm run build`.
- Verify UI changes in the browser (`.claude/launch.json` → `wiki`, port 5179), both
  themes and the narrow (<820px) drawer layout. `npm run build` must stay clean.
