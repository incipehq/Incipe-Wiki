*Things happen while you work: a cable slips, an update arrives. Know where the app tells you, so nothing surprises you on demo day.*

## Notice cards

Cards stack under the top bar, newest in front. Hover the stack to spread it.

| Notice | Means | Button |
| --- | --- | --- |
| **Board disconnected.** | The USB link dropped. Flashing and the serial monitor still work | **Reconnect** |
| **Board found.** | The board is connecting: *Syncing sensors…* | none |
| **Update available · v…** | A new app version | **Update now** |
| **Restart to update** | The update is downloaded | **Restart** |
| **New firmware ready** | New board firmware; your next Verify or Flash uses it | none |

**Done** hides a card. It stays in the Help menu until the problem clears.

## Guided tips

Sometimes Incipe walks you through a task on screen: a ring lights up the control to use and a bubble says what to do, **Step 1 of 4**. Steps tick themselves when the app sees you do them. **What's this?** explains the term; × dismisses the tips.

The glossary words you will meet:

| Word | Meaning |
| --- | --- |
| **Compiling** | Translating your code into instructions the board can run |
| **Flashing** | Copying your program onto the board's memory so it runs on its own |
| **Port** | The USB connection your computer uses to talk to one board |
| **Serial monitor** | A live readout of what your board prints while it runs |

## Help

At the bottom of the project pane:

- **?** (Help) lists hidden **Notices** (click one to show it again) and **Contact us**, which emails the Incipe team.
- **Learn** opens Incipe's video channel.

## You can now

- Read a notice and act on it.
- Follow a guided tip and find help.
