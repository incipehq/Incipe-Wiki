*The monitor will take several conversations: one to read the sensor, one to add warnings, one to go wireless. Keep them under one roof.*

## How it is organised

- A **project** is a folder on your Mac. Its code and chats live together.
- A **chat** is one conversation with Incipe inside a project. Start a new chat for each new job; it keeps the AI focused.

## Start a chat

1. Show the pane with **Switch project**.
2. Hover `climate-reader` and click **+** (**New chat in climate-reader**).
3. The chat is named from your first message. To rename it, open its **⋯** menu › **Rename**, type `Read the sensor`, press Enter.

## Find and tidy

| To | Do this |
| --- | --- |
| Open another project | Click its name, or **Open project** (⌘O) on the landing page |
| Add a project | **+** (**New project**) at the top of the pane |
| Find a chat | **Search projects** (magnifier). It searches project names and chat titles |
| Colour a project | Project **⋯** › pick a colour swatch |
| Move a chat | Drag it onto another project |
| Delete a chat | Chat **⋯** › **Delete**. It goes to deleted chats |
| Get it back | Project **⋯** › **Show deleted chats**, then click the chat (or **⋯** › **Restore**) |
| Rename or move a project | Project **⋯** › **Edit…** |

**Remove project** in **Edit project** only takes the project out of the app. The folder stays on disk.

Chats that belong to no project collect under **Unfiled**. Send a message from one and it files itself into the project you have open.

## You can now

- Start, rename, find, move, delete and restore chats.
- Keep each job in its own chat.
